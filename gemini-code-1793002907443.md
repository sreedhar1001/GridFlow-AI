# GridFlow AI: State Management & Memory Architecture (`memory.md`)

## 1. Memory Hierarchy Overview
GridFlow AI utilizes a three-tier memory architecture to maintain deterministic state across cyclic multi-agent hand-offs while preventing context window overflow:

1. **Tier 1 — Short-Term Graph State (In-Memory `GridState`)**: Managed via LangGraph's `StateGraph`. Tracks active task routing, inter-agent execution logs, retrieved RAG chunks, and retry counters during an active run.
2. **Tier 2 — Episodic Session Persistence (SQLite / Redis Checkpointer)**: Persists state snapshots at every node boundary keyed by `thread_id`. Enables fault recovery, state replay, and Human-in-the-Loop (HITL) inspection.
3. **Tier 3 — Long-Term Semantic Memory (ChromaDB)**: Stores vectorized historical execution summaries, resolved user preferences, and verified code artifacts across sessions.

## 2. Shared Graph State Schema (`GridState`)
All nodes in the execution grid (`Planner_Node`, `Researcher_Node`, `Executor_Node`, `Reviewer_Node`) read from and return partial updates to this exact `TypedDict` schema:

```python
from typing import TypedDict, Annotated, List, Dict, Any, Optional
import operator

def merge_artifacts(existing: Dict[str, Any], new: Dict[str, Any]) -> Dict[str, Any]:
    """Custom reducer to safely merge generated artifacts without overwriting prior keys."""
    merged = existing.copy() if existing else {}
    if new:
        merged.update(new)
    return merged

class SubTask(TypedDict):
    task_id: str
    description: str
    assigned_node: str       # "Researcher_Node" | "Executor_Node"
    status: str              # "PENDING" | "IN_PROGRESS" | "COMPLETED" | "FAILED"
    dependencies: List[str]  # List of prerequisite task_ids
    output_summary: Optional[str]

class ExecutionLogEntry(TypedDict):
    step_number: int
    node_name: str
    task_id: str
    status: str
    reasoning_trace: str
    timestamp: str

class GridState(TypedDict):
    # Session & Input Metadata
    session_id: str
    user_query: str
    
    # DAG Task Planning
    plan: List[SubTask]
    active_task_id: str
    next_node: str           # Controls conditional edge routing
    
    # Append-Only Audit Trail (uses operator.add reducer)
    execution_logs: Annotated[List[ExecutionLogEntry], operator.add]
    
    # RAG & Context Buffer
    retrieved_context: List[Dict[str, Any]]
    
    # Isolated Artifact Storage (uses custom dictionary merge reducer)
    artifacts: Annotated[Dict[str, str], merge_artifacts]
    
    # Circuit Breaker & Error Tracking
    iteration_count: int     # Resets to 0 upon moving to a new task_id
    max_iterations: int      # Default: 3
    error_trace: Optional[str]
    
    # Final Deliverable
    final_response: Optional[str]
